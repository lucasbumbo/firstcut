# First Cut

Análise automática de takes de vídeo para edição. macOS app.

## Download

Baixe a última versão em [Releases](https://github.com/lucasbumbo/firstcut/releases/latest).

## Auto-update

O app verifica atualizações automaticamente ao abrir. Quando uma nova versão é publicada aqui, ela é oferecida na próxima inicialização.
